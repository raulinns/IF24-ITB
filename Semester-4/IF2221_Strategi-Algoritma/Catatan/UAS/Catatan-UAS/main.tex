\section{Outline Keseluruhan Materi}

Bagian ini menyajikan peta belajar ringkas untuk seluruh materi yang
diujikan. Penjelasan mendalam untuk setiap materi tersedia pada
bagian catatan materi masing-masing.

\subsection{Backtracking}
\begin{itemize}
    \item Runut-balik sebagai perbaikan dari \textit{exhaustive
        search} dengan pemangkasan simpul yang tidak mengarah ke solusi.
    \item Pohon ruang status, simpul hidup, simpul-E, simpul mati,
        fungsi pembangkit, dan fungsi pembatas.
    \item Aplikasi: N-Ratu, \textit{sum of subsets}, pewarnaan graf,
        sirkuit Hamilton, dan rute labirin.
\end{itemize}

\subsection{Branch and Bound}
\begin{itemize}
    \item Strategi optimisasi berbasis pohon ruang status,
        \textit{best-first rule}, dan nilai batas.
    \item Fungsi ongkos untuk memilih simpul hidup yang paling menjanjikan.
    \item Aplikasi: 15-Puzzle, TSP, \textit{assignment problem}, dan
        1/0 Knapsack.
\end{itemize}

\subsection{Route Planning}
\begin{itemize}
    \item Pencarian rute pada graf dari status awal menuju status tujuan.
    \item \textit{Uninformed search}: BFS, DFS, DLS, IDS, UCS.
    \item \textit{Informed search}: Greedy Best-First Search dan A*
        dengan fungsi evaluasi.
\end{itemize}

\subsection{String Matching}
\begin{itemize}
    \item Pencarian lokasi kemunculan \textit{pattern} di dalam teks.
    \item Algoritma Brute Force, Knuth-Morris-Pratt (KMP), dan Boyer-Moore.
    \item Fungsi pinggiran KMP dan \textit{last occurrence function}
        Boyer-Moore.
\end{itemize}

\subsection{String Matching with Regex}
\begin{itemize}
    \item Regular expression sebagai notasi pola string yang lebih
        fleksibel daripada \textit{exact matching}.
    \item Character class, range, negasi, metacharacter, quantifier,
        dan boundary matcher.
    \item Penggunaan dasar regex di Python melalui
        \texttt{re.compile}, \texttt{search}, \texttt{match}, dan
        \texttt{findall}.
\end{itemize}

\subsection{Program Dinamis}
\begin{itemize}
    \item Metode optimisasi berbasis tahap, status, keputusan,
        prinsip optimalitas, dan memoisasi.
    \item Pendekatan program dinamis maju dan mundur.
    \item Aplikasi: lintasan terpendek, integer knapsack, coin
        exchange, capital budgeting, dan TSP.
\end{itemize}

\subsection{Teori P, NP, NPC}
\begin{itemize}
    \item Klasifikasi persoalan berdasarkan keterpecahan dan kompleksitas waktu.
    \item Polynomial-time, nonpolynomial-time, tractable,
        intractable, undecidable, deterministik, dan non-deterministik.
    \item Kelas P, NP, NP-Complete, NP-Hard, reduksi polinomial, SAT,
        dan TSP decision problem.
\end{itemize}
