\section{Outline Keseluruhan Materi}

Bagian ini menyajikan peta belajar ringkas untuk seluruh materi yang diujikan.
Penjelasan mendalam tersedia pada section masing-masing materi yang sudah disusun.

\subsection{PDA, termasuk konversi CFG}
\begin{itemize}
    \item Memahami PDA sebagai finite automaton nondeterministik yang dilengkapi stack.
    \item Menguasai definisi formal, fungsi transisi, instantaneous description, dan dua mode penerimaan.
    \item Menguasai konstruksi ekuivalensi CFG ke PDA dan PDA ke CFG.
    \item Berlatih derivasi leftmost/rightmost, parse tree, dan walkthrough konversi CFG/PDA bertipe UAS.
    \item Memahami peran DPDA, prefix property, closure properties CFL via PDA, dan batas determinisme pada CFL.
\end{itemize}

\subsection{CYK}
\begin{itemize}
    \item Membership problem untuk CFL dan kebutuhan Chomsky Normal Form.
    \item Clean-up grammar menuju CNF: nullable, unit pairs, generating, dan reachable symbols.
    \item Tabel segitiga CYK, basis, langkah induksi, dan kondisi $S \in X_{1n}$.
    \item Kompleksitas waktu $O(n^3)$ dan ruang $O(n^2)$.
\end{itemize}

\subsection{Mesin Turing}
\begin{itemize}
    \item Model komputasi umum, definisi formal, fungsi transisi, dan instantaneous description.
    \item Trace eksekusi TM pada input konkret dan strategi mark-scan untuk bahasa seimbang.
    \item Acceptance, halting, transducer, enumerator, recursive language, recursively enumerable language, teorema komplemen RE, dan undecidability.
    \item Encoding, universal language, reduction, PCP, dan Rice's Theorem.
    \item Varian TM serta ekuivalensinya dengan model dasar.
\end{itemize}

\subsection{Compiler}
\begin{itemize}
    \item Sistem pemrosesan bahasa, fase front end, middle end, dan back end.
    \item Lexical analysis, parsing, bottom-up LR/Yacc, semantic analysis, symbol table, error handling, intermediate representation, runtime environment, code generation, dan optimization.
    \item Instruction selection, register allocation, peephole optimization, dan single accumulator code generation.
\end{itemize}

\subsection{Recursive Descent Parser}
\begin{itemize}
    \item Top-down parsing sebagai leftmost derivation.
    \item Satu prosedur per nonterminal, backtracking, left recursion, left factoring, dan hubungan dengan SDT.
\end{itemize}

\subsection{LL(1) Parser}
\begin{itemize}
    \item FIRST, FOLLOW, tabel parsing prediktif, dan kondisi grammar LL(1).
    \item Algoritma nonrecursive predictive parsing berbasis stack, \texttt{synch} entries, dan phrase-level error recovery.
\end{itemize}

\subsection{Intermediate Code}
\begin{itemize}
    \item Tujuan IR sebagai jembatan front end dan back end.
    \item AST, DAG dengan value-number, postfix notation, three-address code, quadruples, triples, BZ/BR, control-flow translation, backpatching, dan optimasi IR.
    \item Constant folding, common subexpression elimination, dead code, unreachable code, dan optimasi loop.
\end{itemize}

\subsection{Interpreter dan Virtual Machine}
\begin{itemize}
    \item Perbandingan compiler, interpreter, bytecode, VM, dan JIT.
    \item Stack-based VM, runtime memory model, garbage collection, HotSpot JIT, dan relasi VM dengan code generation.
\end{itemize}
