Analisis Detail per Topik

Topik Prioritas & Tren Status Catatan Catatan & Gap
CFG Design
81%
P1 → Konsisten sepanjang sejarah Lengkap Tidak ada gap serius. Catatan kuat untuk semua jenis bahasa CFL. Fokus pada latihan berbagai pola: counting (anbn), ratio (a2nbn), bounded (n≤m≤3n), nested, dan mixed constraints.
CFG → PDA Konversi
69%
P1 → Konsisten. Grammar S→aAA muncul 4x! Lengkap Catatan §5.2.11–12 kuat secara konsep. Gap minor: tidak ada contoh walkthrough soal UAS bertipe "convert this grammar to PDA step-by-step". Grammar S→aAA, A→aS|bS|a muncul di tahun 03/04, 04/05, 07/08, dan 10/11 — hafal konversinya.
PDA Design
63%
P1 ↑ Rising dari 08/09 hingga sekarang Lengkap Catatan §5 kuat. Pola soal yang paling sering: (a) equal count — #0 = #1; (b) ratio — #0 = 2×#1; (c) complex constraint language. Penting: pahami perbedaan strategi PDA final state vs empty stack.
CYK Algorithm
50%
P1 ↑ Muncul SETIAP tahun sejak 12/13 (7 tahun berturut!) Sangat Lengkap Catatan §6.2 sangat kuat. Harus bisa mengisi tabel CYK 5×5 secara akurat dan cepat. Grammar yang sering muncul di soal UAS: S→AB|BC, A→BA|a, B→CC|b, C→AB|a. Tidak ada gap signifikan.
CNF Conversion
50%
P1 ↑ Rising kuat sejak 09/10, konsisten Lengkap (1 minor gap) Prosedur 6 langkah ada. Gap minor: angka kompleksitas per tahap tidak tercatat (generating/reachable = O(|G|), unit-pair = O(n²)). Latihan grammar dengan multiple nullable + unit productions berlapis.
PDA → CFG Konversi
44%
P2 → Konsisten, muncul setiap beberapa tahun Lengkap Catatan §5.2.13–14 kuat dengan variabel komposit [pXq] dan aturan produksi. Penting: banyak soal meminta konversi PDA final state ke CFG — ingat harus konversi ke PDA empty stack dulu. Latihan manual dengan PDA 2–3 state.
Derivasi & Parse Tree
31%
P2 → Sporadis, tapi stabil muncul Sebagian Konsep derivasi ada, tetapi catatan tidak punya walkthrough lengkap leftmost/rightmost + parse tree side-by-side. Soal juga sering menanyakan grammar AMBIGUOUS (tunjukkan 2 parse tree berbeda). Tambahkan 1 contoh konkret masing-masing.
FS ↔ ES Konversi PDA
19%
P2 → Muncul 11/12, 15/16, 16/17 Lengkap Catatan §5.2.10 mencakup konstruksi state bantu. Sering dikombinasikan dengan PDA→CFG (konversi FS→ES terlebih dahulu, lalu ES→CFG). Tidak ada gap signifikan.
TM Design ⚠️
19%
P3 → 03/04, 14/15 esai; 20/21 MCQ (tren kembali muncul) KRITIS — Gap Besar Catatan sama sekali tidak punya trace eksekusi TM konkret. Soal UAS TM biasanya: "rancang TM untuk bahasa X, tunjukkan trace pada input Y". Tanpa contoh trace step-by-step, soal ini tidak bisa dikerjakan. Juga tidak ada representasi unary untuk transducer. Prioritaskan perbaikan ini meski frekuensinya P3.
Ambiguous Grammar
19%
P3 → Sporadis Sebagian Konsep ambiguity ada. Soal biasanya: (a) tunjukkan dua leftmost derivation berbeda, atau (b) buat grammar tidak ambiguous (if-then-else adalah contoh klasik). Perlu latihan gambar parse tree manual.
PDA Trace / ID
12%
P4 ↓ Hanya 06/07 dan 07/08, tren menurun Lengkap Konsep ID (q, w, γ) ada di §5.2.5–6. Topik ini tidak muncul lagi setelah 2008. Prioritas sangat rendah.
DFA Minimization
12%
P4 ↓ Hanya 06/07 dan 07/08 Tidak ada di outline TBFO Kemungkinan materi UTS, bukan UAS. Tidak perlu dipelajari untuk UAS berdasarkan historis.
Pumping Lemma
12%
P4 ↓ Hanya 04/05 dan 06/07 Tidak ada di outline TBFO Tidak muncul setelah 2007. Tidak perlu dipelajari mendalam untuk UAS.
Compiler / RDP / LL(1) / IR / VM
0%
? Belum pernah muncul di UAS historis Ada, banyak gap Evaluasi catatan mendeteksi banyak gap (postfix IR, code generation, error handling, dll.), tetapi dari sudut pandang UAS historis, gap tersebut bukan prioritas. Konfirmasi ke dosen sebelum mengalokasikan waktu belajar ke topik ini.

Rekomendasi Alokasi Waktu Belajar

Mengasumsikan ±20 jam waktu belajar tersisa. Alokasi berdasarkan frekuensi UAS × status gap catatan.

Topik Prioritas Alokasi (~) Proporsi Fokus Latihan
CFG Design P1 3 jam
Latihan berbagai pola: counting, ratio, bounded, nested. Minimal 6–8 soal desain CFG dari tahun berbeda.
PDA Design P1 3 jam
Fokus: counting pattern, ratio pattern, multi-symbol constraint. Latihan desain PDA final state dan empty stack.
CFG → PDA P1 2 jam
Hafal prosedur. Latihan manual 3–4 grammar berbeda. Wajib bisa S→aAA dalam tidur.
CYK Algorithm P1 2.5 jam
Tabel filling manual, cepat, akurat. Latihan 4–5 soal CYK dari bundel soal UAS. Muncul setiap tahun sejak 2012.
CNF Conversion P1 2 jam
Urutan: ε → unit → useless → binary. Latihan dengan grammar yang ada nullable dan unit berlapis.
PDA → CFG P2 2 jam
Variabel komposit [pXq], aturan start S → [q0 Z0 p]. Latihan manual PDA kecil (2–3 state).
Derivasi & Parse Tree P2 1.5 jam
Latihan leftmost/rightmost + gambar parse tree manual. Pelajari cara tunjukkan ambiguity (2 parse tree).
TM Design (⚠️ gap kritis) P3 2 jam
Catatan tidak punya trace eksekusi TM. Pelajari pola TM: (a) tabel trace step-by-step; (b) mark-scan technique untuk {0n1n}; (c) TM transducer dengan unary encoding.
P4 topics + lainnya P4 1 jam
Review singkat FS↔ES, PDA trace. Skip compiler topics kecuali dikonfirmasi masuk UAS.
⚠️ Jika dikonfirmasi topik Compiler/RDP/LL1/IR/VM masuk UAS, realokasikan 3–4 jam dari P4 + sebagian P2 ke topik-topik tersebut. Prioritas: (1) postfix IR, (2) error handling compiler, (3) code generation techniques.

Pola Soal Berulang — Wajib Dikenali

Pola-pola berikut muncul berulang kali di UAS, sering dengan grammar atau PDA yang identik atau sangat mirip:

Pola Soal Muncul Di Sesi Detail / Grammar yang Sering Dipakai
"Ubah grammar ini ke PDA empty stack" 03/04, 04/05, 07/08, 09/10, 10/11, 11/12, 12/13, 14/15, 19/20 Grammar S→aAA, A→aS|bS|a muncul 4 kali (03/04, 04/05, 07/08, 10/11). Hafal konversinya. Prinsip: setiap produksi → transisi ε pada stack.
"Buat PDA untuk bahasa dengan counting/ratio" 08/09, 10/11, 11/12, 12/13, 15/16, 16/17, 17/18, 21/22 Pola paling sering: #0 = #1 (equal count), #0 = 2×#1, #1 = 2×#0. Gunakan track A=+1, B=−1 atau sejenisnya.
"CYK — apakah string ini anggota L(G)?" 12/13, 14/15, 15/16, 16/17, 17/18, 19/20, 21/22 (7 tahun berturut!) Grammar yang sering dipakai: S→AB|BC, A→BA|a, B→CC|b, C→AB|a. String yang diuji 4–6 karakter.
"Eliminasi ε/unit/useless → ubah ke CNF" 09/10, 11/12, 14/15, 16/17, 17/18, 19/20 Biasanya grammar dengan nullable berlapis dan unit production. Urutan eliminasi WAJIB benar: ε dulu, lalu unit, lalu useless.
"Konversikan PDA ini ke CFG" 06/07, 09/10, 14/15, 15/16, 16/17, 19/20 Sering PDA 2–3 state dengan Σ={0,1}, Γ={X,Z₀}. Catatan: jika PDA final state, konversi ke empty stack dulu.
"Desain CFG untuk L={a^n b^m | constraint}" Hampir setiap tahun Constraint yang muncul: n=m, n≤m≤2n, m=2n, n>m, i=2j or j=2k. Pelajari pola konstruksi untuk masing-masing.
