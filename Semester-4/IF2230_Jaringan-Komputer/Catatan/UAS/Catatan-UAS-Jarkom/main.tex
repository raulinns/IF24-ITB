\begin{enumerate}

    \item CPMK2. Menjelaskan prinsip dasar medium access layer
    \item CPMK3. Menjelaskan prinsip switched networks dan reliable message delivery

\end{enumerate}

\section{Outline Keseluruhan Materi}

Bagian ini menyajikan peta belajar ringkas untuk seluruh materi yang diujikan.
Penjelasan mendalam tersedia pada section masing-masing materi yang sudah disusun.

\subsection{Transport Layer}
\begin{itemize}
    \item Komunikasi logis process-to-process di atas layanan host-to-host IP.
    \item UDP sebagai simple demultiplexer dan TCP sebagai reliable byte stream.
    \item Socket API, port, segment, checksum, sequence number, ACK, sliding window, flow control, dan adaptive retransmission.
    \item RPC, RTP/RTCP, SCTP, TCP high-speed extensions, QUIC sebagai tambahan pengetahuan umum, serta relasi dengan aplikasi, congestion, wireless, dan security.
\end{itemize}

\subsection{Congestion Control}
\begin{itemize}
    \item Resource allocation, bottleneck, congestion collapse, fairness, dan power.
    \item FIFO, tail drop, Fair Queuing, Weighted Fair Queuing, AIMD, Slow Start, Fast Retransmit, Fast Recovery, Tahoe, dan Reno.
    \item DECbit, RED, TCP Vegas, ECN, QoS, IntServ/RSVP, DiffServ, dan equation-based congestion control.
\end{itemize}

\subsection{Application Layer}
\begin{itemize}
    \item Arsitektur client-server, peer-to-peer, hybrid, socket, port, dan kebutuhan layanan aplikasi.
    \item DNS, HTTP, email, FTP, SNMP, CDN, overlay, web services, P2P, dan multimedia signaling.
    \item Relasi aplikasi dengan TCP/UDP, DNS MX, HTTP persistent connection, TLS, dan routing tingkat aplikasi.
\end{itemize}

\subsection{Wireless Network}
\begin{itemize}
    \item Wireless host, base station, wireless link, infrastructure/ad hoc mode, handoff, dan taksonomi single/multi-hop.
    \item WLAN/Wi-Fi, Bluetooth, 802.11, cellular, path loss, interference, multipath, CSMA/CA, RTS/CTS, association, dan mobility.
    \item Wireless security, TCP over wireless, Mobile IP, MANET routing, dan fitur efisiensi 802.11ax.
\end{itemize}

\subsection{Network Security}
\begin{itemize}
    \item Authentication, confidentiality, integrity, availability, dan model ancaman Alice-Bob-Mallory.
    \item Kerentanan IP/TCP/aplikasi, symmetric cipher, public-key cipher, hash, MAC, PKI, certificate, nonce, challenge-response, Diffie-Hellman, Kerberos.
    \item PGP, SSH, TLS, IPsec, wireless security, firewall, NAT, filtering, malware, botnet, DDoS, dan DNSSEC.
\end{itemize}
