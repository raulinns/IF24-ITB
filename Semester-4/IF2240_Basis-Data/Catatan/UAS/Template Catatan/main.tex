\section{Outline Keseluruhan Materi}

Bagian ini menyajikan peta belajar ringkas untuk seluruh materi yang diujikan. Penjelasan mendalam tersedia pada section masing-masing materi yang sudah disusun.

\subsection{Prinsip OOP SOLID}
\begin{itemize}
    \item Memahami masalah desain buruk: \textit{rigidity}, \textit{fragility}, dan \textit{immobility}.
    \item Menguasai lima prinsip SOLID: SRP, OCP, LSP, ISP, dan DIP.
    \item Mampu membaca cuplikan kode Java, mengidentifikasi pelanggaran prinsip, dan mengusulkan refactoring berbasis abstraksi.
    \item Memahami hubungan SOLID dengan package principles, coupling, stability, dan abstraction.
\end{itemize}

\subsection{Pengenalan Bahasa Java}
\begin{itemize}
    \item Sintaks dasar Java, struktur program, tipe data, class, object, method, dan akses modifier.
    \item Perbedaan model kompilasi Java dengan bahasa lain melalui bytecode dan JVM.
\end{itemize}

\subsection{Padanan Java - C++}
\begin{itemize}
    \item Perbandingan class, inheritance, pointer/reference, memory management, generic/template, dan exception.
    \item Batasan Java seperti single inheritance untuk class dan penggunaan interface untuk multiple typing.
\end{itemize}

\subsection{Java String}
\begin{itemize}
    \item Sifat immutable, string pool, operasi pembandingan, dan penggunaan \texttt{StringBuilder}.
\end{itemize}

\subsection{Java Inheritance}
\begin{itemize}
    \item Relasi \textit{is-a}, overriding, constructor chaining, polymorphism, dan risiko desain hierarki yang salah.
\end{itemize}

\subsection{Java Interface}
\begin{itemize}
    \item Kontrak perilaku, implementasi banyak interface, default method, static method, dan hubungan dengan DIP/ISP.
\end{itemize}

\subsection{Java Generics}
\begin{itemize}
    \item Type parameter, type safety, generic class, generic method, bounded type parameter, dan type erasure.
\end{itemize}

\subsection{Java Generics Wildcard}
\begin{itemize}
    \item Wildcard \texttt{?}, upper bounded wildcard, lower bounded wildcard, dan prinsip PECS.
\end{itemize}

\subsection{Java Collection}
\begin{itemize}
    \item Struktur \texttt{List}, \texttt{Set}, \texttt{Map}, iterator, ordering, hashing, dan pemilihan collection.
\end{itemize}

\subsection{Java Stream API}
\begin{itemize}
    \item Pipeline stream, intermediate operation, terminal operation, lazy evaluation, dan operasi transformasi data.
\end{itemize}

\subsection{Java Exception}
\begin{itemize}
    \item Checked exception, unchecked exception, \texttt{try-catch-finally}, \texttt{throw}, \texttt{throws}, dan desain error handling.
\end{itemize}

\subsection{Java Assertion}
\begin{itemize}
    \item Penggunaan \texttt{assert} untuk memeriksa asumsi internal program selama debugging.
\end{itemize}

\subsection{Java Multithreading}
\begin{itemize}
    \item Thread, runnable task, race condition, synchronization, executor, dan koordinasi eksekusi paralel.
\end{itemize}

\subsection{Java Reflection}
\begin{itemize}
    \item Inspeksi metadata class saat runtime, pemanggilan method dinamis, dan risiko terhadap enkapsulasi.
\end{itemize}

\subsection{Design Pattern}
\begin{itemize}
    \item Pola desain umum sebagai solusi berulang untuk masalah desain OOP, serta hubungannya dengan SOLID.
\end{itemize}
